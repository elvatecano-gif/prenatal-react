# Consultas Pré-Natais (React + Vite)

Protótipo das telas do sistema, com dados fictícios.

    npm install
    npm run dev

Ecrãs: Login, Painel, Pacientes, Registar consulta, Agendamentos.
Regras demonstradas: pesquisa de pacientes, alerta de duplicados (RF07),
histórico por episódio (RF13), sem agendamentos para datas passadas (RN07).
